# WalkDetectionRust

LiDAR(hokuyohub)のクラスターを OSC で受け取り、足が着地した瞬間に、足跡の位置・向き・左右を OSC で送るアプリです。
openFrameworks 製の WalkeDetection3 を、同じ動作のまま Rust に移植したものです。

## 送信データ

足跡を1つ検出するたびに、次のメッセージを1件送ります。

- アドレス: `/footstamp`
- 型タグ: `,ffffi`
- バンドルにはまとめず、1件ずつ送ります。
- タイムスタンプは付けていません。受け取った時点を検出時刻として扱ってください。

| 引数 | 型 | 内容 | 単位・値 |
|---|---|---|---|
| 0 | float32 | 足跡の位置 x | m |
| 1 | float32 | 足跡の位置 y | m |
| 2 | float32 | 足跡の向き x | 長さ1のベクトル |
| 3 | float32 | 足跡の向き y | 長さ1のベクトル |
| 4 | int32 | 左右 | `-1` = 左、`1` = 右 |

### 位置

- 受信した `/hokuyohub/cluster` の重心(arg3, arg4)と同じ座標系です。単位はメートルで、値は変換していません。
- 着地したと判定したフレームの、足(クラスター)の重心です。

### 向き

- 足の進行方向を表す、長さ1のベクトルです。直近 0.5 秒(`directionWindow`)の足の移動から求めます。
- 足がほとんど動いておらず向きを決められないときは、`(0, 1)` を送ります。

### 左右

- 直前の足跡との位置関係から、左右を判定します。
- 判定できなかったときも `-1`(左)を送ります。`-1` は「左、または不明」と考えてください。

### 送るタイミング

- 足の速さが 0.8 m/s(`landingSpeed`)を下回ったときに、着地とみなして送ります。
- 一度足跡を置いた場所の半径 0.2 m(`blockerRadius`)以内では、足がそこを離れて 0.15 秒(`blockerLifeTime`)たつまで、次の足跡を送りません。同じ着地を何度も送らないためです。
- 内部の処理は 60 fps なので、送信の遅れは最大で約 1/60 秒です。

## 送信先と受信ポート

`data/config.json` で設定します。GUI からも変えられます。

| キー | 初期値 | 内容 |
|---|---|---|
| `distIp` | `localhost` | 送信先の IP。`localhost` は IPv4(127.0.0.1)で解決します |
| `distPort` | `10002` | 送信先のポート |
| `listenPort` | `10001` | `/hokuyohub/cluster` を受け取るポート |

`config.json` は、実行ファイルの隣の `data/config.json` から読み込みます。そこになければ、カレントディレクトリの `data/config.json` を読み込みます。

## ビルド

```sh
cargo run --release
cargo test --release   # testdata の入力で、oF 版と出力が一致するかを確かめる
```

GitHub Actions で macOS(arm64)と Windows の実行ファイルをビルドしています。ビルドしたファイルは、Actions の各実行の artifact からダウンロードできます。
